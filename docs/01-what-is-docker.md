# What is Docker?

Docker is a containerization platform that allows applications and services to run in isolated environments called containers.

Containers are lightweight, portable and consume fewer resources than traditional virtual machines.

## Benefits

- Fast deployment
- Portability
- Consistent environments
- Efficient resource utilization
- Easy automation

## Why Network Engineers Use Docker

- Build routing labs
- Test BGP and OSPF
- Simulate network services
- Learn Linux networking
- Run troubleshooting tools
